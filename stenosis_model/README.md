Developed a deep learning-based stenosis segmentation model using the ARCADE coronary angiography dataset. 
Prepared the dataset by converting polygon annotations into binary masks and implemented a U-Net architecture using PyTorch. 
Conducted experiments with BCE and BCE + Dice loss functions to address class imbalance, performed threshold tuning, and evaluated model performance using Dice and IoU metrics. 
Also generated prediction masks and visual overlays to assess segmentation results.
